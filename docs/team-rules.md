# FilmHall team working agreements

Status: Proposed; confirm with the whole team.

- Keep work linked to a backlog item or agreed maintenance task.
- Use feature branches and pull requests rather than committing feature work
  directly to `main`.
- Keep pull requests focused and request at least one teammate review before
  merging, where team size allows.
- Keep secrets and local environment files out of Git; use `.env.example` for
  variable names and placeholders.
- Validate user input and protect customer booking information.
- Update requirements, backlog acceptance criteria, and setup documentation
  when the agreed behavior changes.
- Raise blockers and record decisions so the team and supervisor can follow
  progress.

See [git-workflow.md](./git-workflow.md) for the proposed branch and pull request
workflow.
