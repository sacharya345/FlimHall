# Requirements

## Functional requirements
1. Users must be able to access the application from the frontend.
2. The API must expose health and operational endpoints.
3. The project must support a clean split between frontend and backend responsibilities.
4. Data persistence should be organized through migration and seed workflows.

## Non-functional requirements
- Maintainable folder structure
- Clear separation of concerns
- Ready-to-extend API services
- Frontend build pipeline compatibility
