FilmHall – Team Roles and Responsibilities

Team member	Role	Main responsibilities
Member 1	Frontend Developer + UI/UX Designer	Develop React interfaces, responsive design, navigation, movie listings, showtimes, seat selection, and booking pages.
Member 2	Backend Developer + API Lead	Develop Node.js and Express APIs, authentication, user management, booking logic, and frontend-backend integration.
Member 3	Database Developer + Backend Developer	Design PostgreSQL database, create tables and relationships, implement migrations and queries, and support backend application functionality.

Shared responsibilities
All three team members should participate in:
- Requirements gathering and clarification.
- Product backlog creation and prioritization.
- Sprint planning and daily progress updates.
- Code reviews and GitHub collaboration.
- Testing and bug fixing.
- Documentation and final presentation.
- Azure deployment & release preparation.


Working agreements
1. Each member is responsible for their assigned development tasks.
2. All members participate in weekly sprint planning and reviews.
3. Use GitHub Issues and Projects to track tasks.
4. Create feature branches and review code before merging into main.
5. Communicate blockers and progress regularly.
6. Important technical decisions should be discussed and agreed upon by the team.
