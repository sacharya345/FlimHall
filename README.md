# FlimHall

FlimHall is a full-stack web application with a React frontend and an Express backend.

## Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL-ready structure

## Getting started

### Install dependencies
npm install

### Start the frontend
npm run dev --workspace client

### Start the backend
npm run dev --workspace server

## Project structure
- `client/` contains the frontend application
- `server/` contains the API layer and business logic
- `database/` contains schema and seed-related files
- `docs/` contains project planning and requirements assets
